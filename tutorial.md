# Welcome to Standalone Sensemaking AI

This tutorial will guide you through deploying your own AI-powered survey and analysis platform to Google Cloud in just a few minutes—**no coding or technical expertise required!**

---

## 🚀 1. Start the Installer

1. In the gray code box below, click the **arrow icon ⤓** in the top-right corner (this copies and pastes the command into your terminal on the left):

```bash
chmod +x setup.sh && ./setup.sh
```

2. Press **Enter ↵** on your keyboard in the terminal to run it!

> 💡 **Note:** If Google Cloud Shell displays a popup asking *“Authorize Cloud Shell to make Google Cloud Platform API calls?”*, click **Authorize**.

---

## 💬 2. Answer 3 Quick Prompts

The script will prompt you in the terminal. For the first two questions, you can just press **Enter**:

1. **Google Cloud Project ID:** Press **Enter ↵** to accept your active project.
2. **Google Admin Email:** Press **Enter ↵** to use your logged-in Google account for Global Admin access.
3. **Gemini API Key:** Paste your key and press **Enter ↵**.
   * *Need a free key?* Get one in seconds at **[Google AI Studio](https://aistudio.google.com/app/apikey)** (click *Create API key*).

---

## ☕ 3. Sit Back and Relax!

The deployment is 100% automated and takes about **3–5 minutes**. 

When complete, the terminal will display a **✅ Deployment complete!** message with your live **Admin Dashboard URL**!
