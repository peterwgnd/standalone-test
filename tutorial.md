# Welcome to Jigsaw’s Standalone Sensemaking Platform

This tutorial will guide you through deploying your own AI-powered survey and analysis platform to Google Cloud in just a few minutes—**no coding or technical expertise required!**

---

## 🚀 1. Deploy the Platform

When you are ready, click the **Execute** icon (or copy and paste) on the code box below to run the setup script:

```bash
chmod +x setup.sh && ./setup.sh
```

> **Note:** If Google Cloud Shell displays a popup asking *“Authorize Cloud Shell to make Google Cloud Platform API calls?”*, simply click **Authorize**.

---

## 💬 2. Answer 3 Simple Questions

The script will ask you three quick questions in the terminal:
1. **Google Cloud Project ID**: Simply **press Enter** to accept your currently active project automatically.
2. **Your Google Email**: Enter the email address you use to sign in to Google. This makes you the **Global Admin** so only you can access the dashboard.
3. **Gemini API Key**: This powers your AI survey follow-ups and automatic report generation.
   * *Don't have one?* You can create a free key in 10 seconds at **[Google AI Studio](https://aistudio.google.com/app/apikey)** (click *Create API key*).

---

## ☕ 3. Sit Back and Relax!

The deployment is 100% automated and takes about **3–5 minutes**. The script will show you numbered steps (`[Step 1 of 5]`, etc.) as it builds your platform.

When it finishes, you will see a green **✅ Deployment complete!** message with a clickable link to open your live web dashboard!
